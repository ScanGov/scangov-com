3. ScanGov Standards compliance requirements

The successful vendor must ensure the new website meets the ScanGov Standards published at https://standards.scangov.org. ScanGov scores every government website against these standards in four categories: accessibility, botability, security, and usability. Each requirement below links to the standard that defines it and the guidance for meeting it. The vendor must deliver a site that passes every standard in each category, and will verify compliance with ScanGov scans before acceptance and on an ongoing basis after launch.

3.1 Accessibility

All pages must meet WCAG 2.1 Level AA and pass all 66 ScanGov accessibility standards (full list), including:

  • Color contrast: Sufficient contrast between text and background on every element
  • Alternative text: Every image, image button, and object has meaningful alternative text; captions for video
  • Form labels: Every form field has an associated, visible label and a matching accessible name
  • Link and button names: Every link and button has a discernible name; identical links serve the same purpose
  • Headings and structure: Headings in order, none empty, a main landmark, and a skip link or landmark to bypass repeated content
  • ARIA: Valid roles and attributes, required children and parents, and accessible names on every ARIA widget
  • Language: A valid language declared on the document and on any passage in another language
  • Touch targets: Sufficient size and spacing for touch targets
  • Keyboard access: No positive tabindex values, no focusable content hidden from assistive technology, no meta refresh
  • Tables and lists: Data tables with headers and captions; lists and definition lists correctly structured
  • Zoom: Pinch-to-zoom is not disabled in the viewport meta tag
  • Document basics: Valid doctype, declared character encoding, and images displayed at their natural aspect ratio

3.2 Botability

Search engines and AI assistants must be able to find, crawl, and understand the site:

  • Crawlable: The site permits well-behaved crawlers, including search engines and AI assistants, and does not block them with a firewall, challenge page, or user-agent rule
  • Content available in document: Page content is present in the HTML as delivered, not only after client-side JavaScript runs
  • Robots policy: A valid robots.txt that allows appropriate access
  • Sitemap: A valid XML sitemap of all pages, returning a 200 status and referenced from robots.txt
  • Canonical URLs: A canonical URL on every page to prevent duplicate indexing
  • Descriptive link text: Links describe their destination; no "click here"
  • Language alternates: hreflang annotations where translated pages exist
  • Structured data: GovernmentOrganization Schema.org markup on the site

3.3 Security

  • HTTPS: Every page served over HTTPS with a valid certificate
  • HSTS: HTTP Strict Transport Security header on every response
  • Content security policy: A restrictive CSP header
  • MIME sniffing protection: X-Content-Type-Options: nosniff on every response
  • Clickjacking mitigation: Frame ancestors restricted by CSP or X-Frame-Options
  • security.txt: A security.txt file with current contact information (RFC 9116)
  • No console errors: Pages load without JavaScript errors
  • Paste allowed: No form fields block pasting, so password managers and assistive tools work
  • .gov domain: The site is served from a .gov domain, or another sponsored top-level domain, where the organization is eligible

3.4 Usability

  • Page titles: A unique, descriptive title on every page
  • Page descriptions: A meta description on every page
  • Readability: Content written in plain language. ScanGov scores an Automated Readability Index of grade 8 or below as passing; mature government content teams target grade 6. Applies to the Plain Writing Act and OMB M-23-22
  • Mobile viewport: A viewport meta tag so pages render correctly on mobile devices
  • www resolution: Both www and non-www hostnames resolve to the site
  • First Contentful Paint: Within 1.8 seconds
  • Largest Contentful Paint: Within 2.5 seconds
  • Interaction to Next Paint: Under 200 milliseconds
  • Time to First Byte: Under 0.8 seconds
  • Cumulative Layout Shift: 0.1 or less; no unexpected content shifts
  • Open Graph social sharing: Open Graph site name, type, title, description, URL, image, and image alt text on every page so shared links preview correctly
