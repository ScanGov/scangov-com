About

This tool checks whether ScanGov can reach your website using two methods:

  • Standard HTTP fetch
  • Playwright browser fallback

If both methods fail, ScanGov may not be able to audit your site.

Common issues

  • Web application firewalls (WAFs) blocking automated requests
  • Server returning error status codes (403, 503, etc.)
  • SSL/TLS certificate problems
  • Site not responding within timeout period
