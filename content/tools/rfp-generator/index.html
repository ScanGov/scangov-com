About the RFP generator

Writing a website redesign request for proposal (RFP) means turning accessibility, security, performance, and search and AI readiness into requirements a vendor can be held to. This generator writes the ScanGov Standards into section 3 of a complete RFP, links every requirement to the standard that defines it, and adds contract terms so compliance is verified by checks, not promises. Nothing you enter is stored.

What the RFP requires

Section 3 of the generated RFP covers the five categories ScanGov scores, with each requirement linked to its standard and guidance:

  • AI and search readiness: the site can be crawled and understood by search engines and AI assistants, with content in the HTML rather than only after JavaScript runs.
  • Accessibility: WCAG 2.1 AA and all 66 ScanGov accessibility standards, from color contrast to touch target size.
  • Security: HTTPS, HTTP Strict Transport Security (HSTS), a content security policy, security.txt, and the other headers the Cybersecurity and Infrastructure Security Agency (CISA) and the Open Worldwide Application Security Project (OWASP) recommend.
  • Usability: Core Web Vitals thresholds, page titles and descriptions, mobile viewport, and social sharing tags.
  • Readability: content written in plain language, scored by reading grade level on every page.

The rest of the document is a conventional RFP skeleton you can edit: background, functional requirements, content management system (CMS) and integrations, design, deliverables, timeline, proposal requirements, evaluation criteria, and contract terms.
